# K1NGANG0RR0T's Sodium Mod Options
*(fork of Sodium Options Mod Compat 1.0.0)*

This is a fork of [Sodium Options Mod Compat](https://github.com/txnimc/SodiumOptionsModCompat) **1.0.0** by [toni (txnimc)](https://github.com/txnimc) and DeeChael,
ported to **Sodium 0.8+ on Minecraft 1.21.1 (NeoForge)**. All credit for the original mod goes to toni and DeeChael.

- Original on Modrinth: <https://modrinth.com/project/Yg1VT27P>
- Original on CurseForge: <https://www.curseforge.com/projects/1146393>
- Original source: <https://github.com/txnimc/SodiumOptionsModCompat>

## What changed in this fork
Adds Sodium options pages for **Continuity**, **Dynamic FPS** and **Entity Texture Features** through Sodium 0.8's native config API (`sodium:config_api_user`),
so they show up in K1NGANG0RR0T's Sodium Options (Reese's Sodium Options) as well as Sodium's own screen. The old page classes and mixins are gone;
the EMF integration was dropped. The mod id is still `sodiumoptionsmodcompat`.

Version `1.0.0-k1ng.sodium0.8` = fork of upstream 1.0.0.

## Requirements
- Minecraft 1.21.1, NeoForge
- Sodium 0.8+
- Optional: K1NGANG0RR0T's Sodium API (`sodiumoptionsapi`)
- The mods you want pages for (Continuity, Dynamic FPS, Entity Texture Features)

Do not run it alongside the original Sodium Options Mod Compat; they share the same mod id.

## Building
```
./gradlew build
```
The jar is written to `build/libs/`.
